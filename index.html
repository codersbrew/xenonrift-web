Join or Host a Dedicated Server

Connect to the official persistent war room or spin up your own community dedicated server.

Connect to Official Server

The official dedicated server operates 24/7 on high-performance infrastructure with low latency routing across North America and Europe.

  • 1
    Launch the Client

    Open Xenon Rift on macOS or iOS.

  • 2
    Enter Call Sign & Faction

    Input your pilot call sign and select Cyan Vanguard, Ember Syndicate, or Balance Me.

  • 3
    Set Address & Join

    Verify server address is set to game.xenonrift.com:7770 and click Join Server.

CLI Quick Connect (macOS)
"Builds/macOS/XenonRift.app/Contents/MacOS/Xenon Rift" -connect game.xenonrift.com -port 7770 -faction cyan -name Maverick

Host Your Own Dedicated Server

Anyone can host a community dedicated server on macOS or Linux. Dedicated servers run completely headless without graphics rendering.

macOS Headless Server
"XenonRift.app/Contents/MacOS/Xenon Rift" -batchmode -nographics -server -port 7770 -teamsize 10
Linux Server (x86_64)
./XenonRiftServer.x86_64 -port 7770 -teamsize 10 -statuslog 30
Key Server Command-Line Arguments
-port <n>: UDP game port (default: 7770)
-teamsize <1-10>: Ships per faction (default: 10, for 10v10)
-mode <tdm|depot|ovd>: Pin specific match mode (optional)
-statuslog <s>: Log status interval in seconds
